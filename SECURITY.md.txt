# Security Guidelines

This repository contains documentation and screenshots from a completed AWS VPC Peering lab.

## Sensitive Information

- AWS access keys, secret keys, passwords, and session tokens must never be committed.
- Private SSH keys (`.pem` files) must not be uploaded.
- Review screenshots and documents for sensitive information before publishing.
- Do not include unnecessary account identifiers or personal information.

## AWS Resources

The lab environment was intended to be cleaned up after testing. Refer to the project documentation for the scope of the completed work.

## Reporting an Issue

If you identify exposed sensitive information, please notify the repository owner and avoid sharing the information publicly.
